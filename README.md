# OpenGL-3D-Viewer

## Overview

OpenGL-3D-Viwer is a C++ application designed for loading, visualizing, and studying 3D models using the OpenGL graphics API. 

The project focuses on exploring modern computer graphics concepts, 
including rendering pipeline organization, shader-based rendering, 
GPU resource management, and 3D data visualization.

The project was developed as part of two graduation qualification 
projects at:

- Volga State University of Telecommunications and Informatics (PSUTI)
- Samara State Medical University (SamSMU)

Both graduation projects were successfully defended and received 
the highest grade — 5 (Excellent).

---

## Features

- Loading and rendering 3D models
- Custom OpenGL rendering pipeline
- Shader-based visualization
- Vertex and index buffer management
- 3D transformations
- Interactive visualization of 3D objects

## Technologies

| Technology | Purpose |
|---|---|
| C++ | Core application development |
| OpenGL | Rendering API |
| GLFW | Window and input management |
| GLAD | OpenGL function loading |
| GLM | Mathematical operations |
| Assimp | 3D model importing |

## Project Goals

The main goals of the project:

- Research computer graphics principles and rendering techniques
- Develop a custom 3D visualization solution
- Implement a basic rendering architecture using OpenGL
- Study methods of representing and processing 3D data
- Create an extensible foundation for future medical visualization applications
